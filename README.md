# RokaScape

A browser-based, OSRS-inspired port of the original Java text adventure.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Play

1. Enter a hero name and click **New Hero** or **Continue** (loads from browser localStorage).
2. Click monsters in the viewport to fight; click NPCs to talk.
3. Use **Shop** and **Travel** buttons in the chatbox panel.
4. Right-click inventory items to Eat, Equip, or Drop.

## Original Java version

The console Java sources are preserved in `java-original/`.
